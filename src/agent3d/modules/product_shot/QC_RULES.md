# Rules & QC: Product Shot (MVP)

Every defect spotted by eye **must** be logged here, then turned into a rule in the verbs and/or an automatic numeric check. This file is the agent's "skill memory".

Format: ID · defect/risk · found by · fix · numeric check (QC) · pass threshold · status
